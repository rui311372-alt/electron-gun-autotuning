# 电子枪离线最优点程序

这是论文第二阶段“离线识别最优点”的已有程序副本，不是在线贝叶斯调参程序。它只读取保存的数据，不连接电子枪、不控制电源、不采图，也不重新运行高斯过程。

## 文件与运行方法

- `stable_working_point_round10.py`：原分析程序，内容未修改。
- `candidate_data.csv`：论文已有四次运行的数据，共180个有效候选；不是九工况全量数据，也不包含后续十次运行的全部原始记录。
- `reference_results.json`：原分析保存的四组参考结果。
- `run_offline.py`：运行入口，只负责传入文件路径并新建输出目录，不改算法。
- `run_example.cmd`：双击运行附带的四组数据。窗口运行完后按任意键关闭。

需要 Python 3.10 或更高版本；算法仅使用标准库，无需安装第三方包。本机已使用 Python 3.11 试运行。

也可以在此文件夹打开终端运行：

```text
python -X utf8 run_offline.py
```

分析自己的数据时，将下方路径替换为实际 CSV 路径：

```text
python -X utf8 run_offline.py "D:\my_data\candidate_data.csv"
```

如果双击提示找不到 Python，请安装或启用 Python，或在终端使用已安装 Python 的完整路径运行。原程序还会执行敏感性和前缀分析，因此耗时比只计算四个最优点稍长；请等待完成。

每次结果保存在 `results/运行时间/` 中，不覆盖上一次输出：

- `optimal_points.csv`：各运行最优电压、score、低波动分支入口及统计量，可用 Excel 查看。
- `segments.csv`：连续分段范围及高/低波动标签。
- `results.json`：完整主分析结果与参数。
- `sensitivity.csv`：不同聚合方式、分段长度、分布等设置的敏感性结果。
- `prefix.csv`：长预算运行前缀结果；没有满足条件的长预算运行时不生成。

## 输入数据

CSV 使用 UTF-8 编码，每行代表同一候选设定下的3次取图，必须包含以下列：

| 列名 | 含义 |
| --- | --- |
| run | 运行名称；不同实验必须用不同名称，不能混为一次运行 |
| iteration | 候选测量顺序，整数 |
| uc_set | Uc 设定值，单位 V；程序按此列排序与报告最优电压 |
| uc_feedback | Uc 反馈值，单位 V；保留记录，不用于替换设定值排序 |
| shot1、shot2、shot3 | 3次取图分别得到的单图 score，单位 px |

单图 score 对应论文的双边缘 FWHM 合成量 sqrt(x1²+x2²)。本程序不从图像重新提取 x1、x2，也不核验单图 score 公式；需要输入已经正确计算好的数值。

`online_score`、`median3`、`mean3`、`cv3` 等附加列可以保留，但默认主分析会从 shot1～shot3 重新计算候选 score 和 CV。

输入应先按在线实验规则完成有效性和一致性筛选，并确认图像与设备记录可追溯。本程序仅筛除空值、非数值等异常，不自动核验原图，也不重新执行最接近两次相对差不超过10%的判定；不能将未经筛选的新 CSV 直接当作有效数据。

## 主分析逻辑

1. 同一次运行的有效候选按 Uc 升序排列。
2. 用3次 score 的样本标准差计算 CV（以百分数数值表示），再计算 ln(CV+10^-6)。
3. 用 Laplace 分段代价、动态规划和 BIC 选择连续分段，默认最小分段长度为4个候选。
4. 用每段 log(CV) 的中位数代表该段，按候选数量加权进行二类聚类，区分相对高波动和低波动段。
5. 从最高 Uc 端向低电压方向保留连续低波动段，遇到高波动段停止。
6. 只在该终端低波动分支内比较候选 score，选择最小值对应的实测候选；相同 score 优先选择较低 Uc。

主分析中的候选 score 是“3次取图中相对差最小的两次 score 的平均值”，不是三次中位数；CV 仍使用全部3次。5%仅可作结果统计参照，不是主算法的分支划分阈值，也没有固定40%搜索下界。

输出中的历史字段 `transition_lower_uc`、`transition_upper_uc` 应理解为“终端低波动分支起始区间”，不是唯一物理转变点或置信区间。

## 原程序的适用边界

此次仅复制和验证已有版本，没有擅自改动算法。与目前论文的完整表述相比，以下边界需要知道：

1. 原程序的 Laplace 代价使用简化式。当段内尺度触发10^-6的数值下限时，它不等同于论文附录C中保留残差项的完整似然式。已核查附带四组数据全部长度不少于3的候选区间均未触发该下限，因此不影响上述结果；分析大量完全相同或极接近 CV 的新数据前，应先修正并验证该边界实现。
2. 当候选太少、只识别出一个区间或最高 Uc 端不是低波动状态时，程序会报错，不强行给出最优点。程序未额外实现“两个状态中心差多大才可清楚区分”的阈值；不能把成功输出理解为两状态已通过显著性检验。
3. 当前识别的是本次采样覆盖范围内、相对低波动分支中的最低候选 score，不保证全范围数学全局最优，也不替代长期稳定性或设备安全验证。
