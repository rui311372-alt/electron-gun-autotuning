# 资料整理与图片发布说明

## 复制范围

- `代码/LW` 对应 `code/online`。
- `代码/电子枪离线最优点程序_20260923` 对应 `code/offline`。
- 删减后的 `实验数据` 对应 `data`，保留实验分类及原文件名。
- 不从之前已删除的目录补回文件，不混入其他版本的实验数据。
- 原程序和数据文件采用原样复制，不修改单图 score、聚合规则、CV、实验结果或设备参数。

## 图片的独立发布

现有1126个图像文件（553个TIF、573个PNG）作为 [images-v1 预发布版本](https://github.com/rui311372-alt/electron-gun-autotuning/releases/tag/images-v1)的附件提供，与代码提交 `66aed4154423e8f4f8f2bf057c3c82871e52916e` 对应。ZIP保留 `data/` 下原目录与文件名，同时提供逐文件清单和SHA-256校验文件。文件选择与当前作者提供的数据快照一致，不补回已删除的历史资料，不按有效候选数量裁减归档中的图像。

图片仍由 `.gitignore` 排除普通提交；无需取消忽略规则，也未引入Git LFS。新克隆副本需要另行下载并恢复图片包。访问当前私有仓库的Release及附件需要相应账号权限。下载入口和目录恢复方法见[中文项目说明](../README.zh-CN.md)。

## 仍只在本地保留的内容

厂商 SDK 及其二进制适配模块、离线历史输出保留在本地副本，由 `.gitignore` 阻止普通提交；它们不包含在图片Release中。SDK再分发权限和安装兼容性尚未确认。
