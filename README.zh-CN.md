# 电子枪图像反馈自动调参

[English](README.md) | **简体中文**

基于贝叶斯候选推荐与稳定性约束最优点选取的真实微焦点电子枪图像反馈自动调参项目。

本仓库包含实验控制程序、无需连接设备的离线分析示例，以及部分实验表格和报告。现有实验图片通过 [images-v1 发布页](https://github.com/rui311372-alt/electron-gun-autotuning/releases/tag/images-v1)单独提供。**这份图片快照尚未覆盖论文中的所有实验，仓库也不是安装后即可直接运行设备的完整软件包。**

## 项目概述

方法分为两个阶段：

1. **在线采集与搜索：** 将设备控制、反馈判稳、重复取图、图像评价和贝叶斯候选推荐组成自动化测量闭环。
2. **离线最优点选取：** 根据保存的测量数据识别与最高采样阴极电压端连续相连的低波动分支，再在该分支内选择候选 score 最小的实测点。

在线阶段负责采集数据和推荐候选，离线阶段负责确定最优点。离线程序不控制电子枪，也不重新运行高斯过程。

### score 的含义

图像评价程序将两个正交方向的边缘半高全宽（FWHM）合成为：

$$
\mathrm{score}=\sqrt{x_1^2+x_2^2}.
$$

两个宽度及 score 的单位均为像素（px）。在相同成像与处理条件下，score 越小表示两个方向的图像边缘综合尺度越小。它是与聚焦状态相关的图像评价量，不代表电子束的全部性能，也不是经过物理尺寸标定的束斑直径。

默认离线分析中，每个候选包含 **3 次取图**的 score。**候选 score 取相对差最小的两次 score 的平均值**；变异系数 **CV 则使用全部 3 次 score 和样本标准差计算**。因此，候选 score 较低不等于该候选所在区域稳定。

## 快速开始：离线示例

**环境要求：** Python 3.10 或更高版本。这个离线示例仅使用 Python 标准库，不需要相机、电子枪、厂商 SDK 或第三方 Python 包。

在仓库根目录打开终端，运行：

```bash
python -X utf8 code/offline/run_offline.py
```

Windows 用户也可以双击 `code/offline/run_example.cmd`，前提是已安装 Python，且系统能够找到 `python` 命令。

分析其他已经完成有效性筛选的 CSV 时，在命令后加上文件路径：

```bash
python -X utf8 code/offline/run_offline.py "path/to/your/candidate_data.csv"
```

每次运行会新建 `code/offline/results/<时间戳>/`，不会覆盖上一次结果。程序同时执行敏感性和前缀分析，因此比仅计算最优点耗时更长。新生成的结果由 Git 忽略；已有 `reference_results.json` 纳入版本管理。

| 输出文件 | 内容 |
| --- | --- |
| `optimal_points.csv` | 最优电压、候选 score、分支起始区间及统计量 |
| `segments.csv` | 电压分段及高、低波动标签 |
| `results.json` | 主分析设置、结果及被排除的输入行 |
| `sensitivity.csv` | 不同聚合、分段及其他分析设置下的结果 |
| `prefix.csv` | 符合条件的长预算运行前缀分析；其他输入不一定生成此文件 |

### 输入格式

CSV 使用 UTF-8 编码，每行对应一个候选，必须包含以下列：

| 列名 | 含义 |
| --- | --- |
| `run` | 运行名称；相互独立的运行不能混为一组 |
| `iteration` | 该次运行中的采集顺序，整数 |
| `uc_set` | 阴极电压设定值，单位 V；用于排序及报告最优点 |
| `uc_feedback` | 电压反馈记录，单位 V；与设定值分别保留 |
| `shot1`、`shot2`、`shot3` | 同一候选下 3 次取图各自的 score，单位 px |

可以保留额外列。主分析从 `shot1`～`shot3` 重新计算候选 score 和 CV，不直接沿用存储的汇总列。程序**不会**重新提取图像特征、核验原图，或重新执行在线阶段最接近两次相对差不超过 10% 的一致性判断。新数据必须先按实验规则完成有效性与一致性筛选。

## 离线选点方法与结果含义

默认分析对每次运行分别执行以下步骤：

1. 按 `uc_set` 升序排列候选，计算以百分数数值表示的 CV，再计算 `ln(CV + 1e-6)`。
2. 使用 Laplace 分段代价、动态规划和 BIC 确定连续分段，默认每段至少包含 4 个候选。
3. 以各段对数 CV 的中位数代表该段，按候选数量加权划分为高、低两类波动状态。
4. 从最高采样电压向低电压方向保留连续的低波动分段，遇到高波动段即停止。
5. 在这一终端低波动分支内选取候选 score 最小的实测点；score 相同时优先选择较低电压。

“低波动”是相对于本次运行数据的分类结果。主分析既不采用固定的 5% CV 阈值，也不设置固定的 40% 搜索下界。输出中的历史字段 `transition_lower_uc` 和 `transition_upper_uc` 表示**终端低波动分支起始区间**，不代表唯一的物理转变点或置信区间。

当前保留程序的主要适用边界：

- 候选太少、分段不足，或最高电压端被归为高波动状态时，可能无法选点。成功输出结果也不代表两类状态已通过统计显著性检验。
- 简化 Laplace 代价在尺度下限 `1e-6` 生效时，与完整似然存在差异。详细使用说明已记录附带示例的相关区间没有触发该下限；分析 CV 大量重复或极为接近的新数据前，应先核查这一实现边界。
- 最优点仅指已识别分支内的最佳**实测候选**，不保证是数学全局最优，也不能直接作为长期稳定或安全运行的认证结果。

更多实现细节见[离线程序使用说明](code/offline/使用说明.md)。

## 在线程序与设备要求

`code/online/` 保留提供的设备控制、相机、图像处理及优化程序，包含多个 `bayes_optlr_*.py` 变体。开展设备复现前，需要确认每组实验实际使用的脚本和配置。

**不要把这些脚本当作离线演示直接启动。** 它们可能连接真实高压设备。设备运行需要授权操作人员、适配设备的配置、相机驱动和 SDK，并遵守实验室安全规程。

现有[在线依赖文件](code/online/requirements.txt)并不是覆盖全部变体的完整锁定环境。例如，贝叶斯脚本导入 `skopt`，但其对应的 `scikit-optimize` 包尚未列入依赖文件。相机 SDK 和二进制适配模块因再分发权限及兼容性尚待确认，未纳入 Git。本次说明文件更新没有验证在线设备运行流程。
