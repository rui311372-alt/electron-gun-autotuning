# Electron Gun Autotuning

真实电子枪图像反馈自动调参与离线最优点分析的研究项目。

本地整理版包含作者提供的程序、实验表格、测量记录和图像副本。在线控制与离线分析分开保存；高 Uc 稳定性测试和断电复测分开保存，不合并样本量。

## 目录

```text
code/
  online/    原 LW 程序：设备控制、图像采集与在线搜索
  offline/   已有离线分析程序、示例候选数据及参考结果
data/        按原实验分类保存的材料
docs/        整理说明及公开前检查事项
```

## 本地副本与 GitHub 内容的区别

本次保留源文件内容和实验目录名称，没有改算法、重算实验结果或操作设备。

- 图像已复制到本地 `data/`，但由 `.gitignore` 排除，不随普通 Git 提交上传。完整图像的存储方式和下载入口尚未确定。
- 相机厂商 SDK 及其二进制适配模块已保留在本地原相对位置，但由 `.gitignore` 排除；再分发权限尚未确认。
- 缓存、编辑器配置、临时会话和指定的 SDK 运行日志未复制。
- 离线程序旧运行输出保留在本地并忽略；`reference_results.json` 作为参考结果保留在版本管理范围内。

因此，线上仓库或新克隆副本不会自动包含完整图像和 SDK。本版不能宣称所有实验均可从零完整复现。

## 离线分析入口

`code/offline/run_offline.py` 是已有包装入口，默认读取同目录的 `candidate_data.csv`。其运行方式为：

```text
python -X utf8 code/offline/run_offline.py
```

该程序不连接电子枪或控制电源。已有说明要求 Python 3.10 或更高版本，使用标准库；本次复制不代表重新完成了运行验证。输入约定、参考结果和算法边界见 [离线程序使用说明](code/offline/使用说明.md)。附带 CSV 是已有四次运行的示例，不是九工况或十次运行的全部原始记录。

## 在线设备程序

`code/online/` 保留原目录结构和程序变体，不指定其中某个变体为全部实验的唯一正式入口。在线程序涉及真实高压设备和相机，不能作为离线演示直接运行。

原依赖文件、配置和相机适配代码保持不变。公开前仍需确认正式实验入口、依赖版本、SDK 安装方法及设备运行条件。请勿将本次整理视为硬件安全验证。
